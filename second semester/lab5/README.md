# Лабораторная работа №5

## ДЕРЕВЬЯ

Задача лабораторной работы — закрепить навыки реализации динамической структуры данных — бинарное дерево поиска, с применением указателей, а также навыки сравнения эффективности структур (дерева поиска и отсортированного списка) в задачах поиска элементов.
В рамках этой работы необходимо написать программу, которая реализует бинарное дерево поиска в виде иерархической связанной структуры с применением указателей. Использование готовых решений для реализации дерева и его операций не допускается.

В данной работе необходимо реализовать следующие обязательные операции для бинарного дерева поиска:
• Добавление нового элемента в дерево;
• Обход дерева различными способами с выводом значений вершин:
    o  	прямой (в глубину);
    o	обратный;
    o	горизонтальный (в ширину);
    o	симметричный порядок;
• Поиск элемента в дереве;
• Нахождение наибольшего и наименьшего элемента непустого дерева;
• Удаление элемента из дерева;
• Проверка два дерева на равенство;
• Подсчёт числа вершин на заданном уровне непустого дерева;
• Копирование дерева.

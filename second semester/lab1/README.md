# Лабораторная работа №1

## ДИНАМИЧЕСКИЕ СПИСКИ 

Задача лабораторной работы — закрепить навыки реализации динамической структуры данных — списков, с применением указателей при её реализации.
В рамках этой работы необходимо написать программу, которая решает заданную задачу с помощью создания и обработки одного или нескольких списков в выбранной предметной области в соответствии с вариантом задания.
Вариант реализации списка (однонаправленный или двунаправленный) выбирается самостоятельно. Операции создания и работы со списком должны выполняться посредством указателей.

## Задание 
5. Поликлиника.
	Сируктура: ФИО пациента, возраст, врач, дата приёма	
    Действия:
    1) Запись пациента к врачу (добавление записи в список приёма); 
    2) Отмена записи; 
    3) Изменение врача; 
    4) Поиск пациентов по имени; 
    5) Поиск записи по врачу или дате.

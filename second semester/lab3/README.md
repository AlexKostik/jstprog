# Лабораторная работа №3

## ХЕШ-ТАБЛИЦЫ

Задача лабораторной работы — закрепить навыки реализации динамической структуры данных — хеш-таблицы, с применением указателей, а также навыки сравнения эффективности структур (словаря и хеш-таблицы) в задачах поиска элементов.
В рамках этой работы необходимо написать программу, которая решает по отдельности две заданные задачи поиска в выбранной предметной области в соответствии с вариантом задания, а также выяснить и продемонстрировать, где выполняется поиск быстрее: в словаре или хеш-таблице, рассмотреть различия и сделать соответствующие выводы.
Для каждой задачи поиска реализовать свой словарь и хеш-таблицу, провести эксперименты, фиксируя время выполнения операций поиска элементов в указанных структурах, используя средства для точного замера выполнения кода (например, std::chrono). Использование готовых решений для реализации словарей, хеш-таблиц и их операций не допускается.
Хеш-таблица должна уметь работать с коллизиями. Выбор хеш-функций выбирается самостоятельно. Моделирование значений хранимых данных выбирается самостоятельно. Минимальное требуемое количество записей – 50. Для двух задач поиска моделируемые данные должны быть идентичные.

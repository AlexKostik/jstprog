# Лабораторная работа №2

## ПРИОРИТЕТНЫЕ ОЧЕРЕДИ

Задача лабораторной работы — закрепить навыки реализации динамической структуры данных — очереди с приоритетом, с применением указателей, а также навыки моделирования простой системы массового обслуживания в заданной предметной области.
Система массового обслуживания (СМО) — математическая модель для анализа процессов, где случайным образом поступают запросы (заявки), которые обслуживаются ограниченными ресурсами (каналами/устройствами). Периодически заявки поступают в систему (характеризуется законом поступления, например случайным образом). Если канал свободен, то заявка мгновенно обслуживается каналом, иначе ждет в очереди. Канал может обрабатывать только одну заявку. Время обработки заявки также характеризуется распределительным законом или выбирается исследователем самостоятельно. После завершения обслуживания заявки уходят из системы. Анализ СМО подразумевает нахождение характеристик: вероятность отказа/ожидания, среднюю длину очереди, среднее время ожидания и пребывания заявки, загрузку каналов.
В рамках этой работы необходимо написать программу, которая моделирует работу СМО с одним каналом, через работу очереди с приоритетом, и рассчитывает статистические данные СМО. Время моделирования СМО, распределение времени обслуживания заявки и закон поступления потока заявок выбирается самостоятельно и согласовывается с преподавателем.
Очередь и работа с ней реализуется с применением указателей. Использование готовых решений для реализации очередей и их операций не допускается. 

В данной работе необходимо реализовать следующие обязательные операции для очереди:
• Вставка с приоритетом (enqueue);
• Извлечение заявки на обслуживание (dequeue и pop);
• Вывод очереди на экран;
• Сбор и обработка базовой статистики СМО (индивидуально по варианту).

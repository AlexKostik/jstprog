# Лабораторная работа №4

## ГРАФЫ

Задача лабораторной работы — закрепить навыки реализации динамической структуры данных — графы, с применением указателей, а также решения задачи нахождения наикратчайших путей.
В рамках этой работы необходимо написать программу, которая реализует граф в виде списка смежности вершин с моделированием связей объектов и решении задачи в выбранной предметной области в соответствии с вариантом задания. Минимальное требуемое количество моделируемых объектов – 20. Использование готовых решений для реализации графа и их операций не допускается.
Кроме программного представления графа необходимо также отдельно изобразить граф в виде схемы с отображением связей и весов.

В данной работе необходимо реализовать следующие обязательные операции для графа:
• Вставка новой вершины;
• Удаление вершины (с удалением всех инцидентных рёбер);
• Вставка ребра;
• Удаление ребра;
• Поиск вершины (по идентификатору/ключу);
• Поиск ребра;
• Вывод графа методом BFS;
• Вывод графа методом DFS;

# Задание
5. Сеть компьютерных узлов офиса.
Вершины: компьютеры/роутеры.
Рёбра: сетевые соединения (неориентированные или ориентированные для VLAN/маршрутизации).
Вес: задержка (ms).	Кратчайший путь: минимальная задержка между узлами.

# Лабораторная работа №10

Цель работы: написать программу сравнения двух различных сортировок

 > Каждый из Вас, прежде чем работать над заданием, должен обозначить и согласовать свой выбор с преподавателем, также определить критерии сравнения. Критерии сравнения выбрать, например, следующие: количество итераций, время работы, скорость работы на отсортированном массиве и нет и др.

Виды сортировок: Пузырьком, Шейкерная, Расческой, Вставками, Шелла, Деревом, Гномья, Выбором, Пирамидальная, Быстрая, Слиянием, Подсчетом, Блочная, Поразрядная, LSD, MSD, Битонная, Timsort, Плавная и др.

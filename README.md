# jstprog

Репозиторий с лабораторными и практическими заданиями по программированию на языке C++ для университета.

Мой вариант: №5.

---

## 📌 О проекте

В репозитории собраны:

- лабораторные работы;
- лекционный материал;
- полезные ресурсы;
- дополнительные заметки по заданиям.

Проект используется как учебная база для изучения:

- основы языка C++;
- структур данных и алгоритмов;
- объектно-ориентированного программирования;
- работы с файлами и памятью.

## ⚙️ Installation

### Требования

Для запуска программ необходимо:

- установить компилятор с поддержкой C++20;
- установить Git;
- использовать Windows, Linux или macOS.

### Клонирование репозитория

```bash
git clone <ссылка-на-репозиторий>
cd jstprog
```

---

## 🚀 Usage

### Переход в папку лабораторной работы

```bash
cd "first semester/Lab1"
```

### Компиляция программы

```bash
g++ main.cpp -std=c++20 -o main
```

### Запуск программы

#### Windows

```bash
main.exe
```

#### Linux / macOS

```bash
./main
```

## 📝 Содержание

## 🚀 Как использовать

1. Перейти в нужную папку с заданием:
'''bash'''
'cd Lab1'
2.	Скомпилировать программу:
'g++ main.cpp -o main'
3.	Запустить:
'./main'

⚡ Примечания
	•	Код написан с использованием стандарта C++20.
	•	Большенство лабораторных работ снабжены комментариями для пояснения логики.
